# BookOrbit for Mihon

Mihon에서 개인 BookOrbit 서버의 만화를 읽기 위한 비공식 Android 확장입니다. **BookOrbit I / II / III**의 3개 소스를 제공하며, 각 소스에서 **필터 → 라이브러리**로 여러 라이브러리를 탐색합니다. CBZ·CBR·CB7 형식을 지원합니다.

Android 8.0 이상이 필요합니다. 기존 1.6.1은 Mihon 0.21.3과 BookOrbit 3.8.0에서 검증했습니다. 1.6.3은 기본 라이브러리 설정을 제거하고 인기에서 모든 라이브러리를 표시합니다. 로컬 단위 테스트 48개와 빌드·서명 검사를 통과했고 사용자가 동작을 확인했습니다. 기기·실서버 자동 재검증은 수행하지 않았습니다. [1.6.3 Release](https://github.com/10000Je/mihon-bookorbit-extension/releases/tag/v1.6.3) 또는 아래 확장 스토어에서 설치할 수 있습니다.

## 설치

1. Mihon의 **더보기 → 설정 → 탐색 → 확장 스토어**에 아래 주소를 추가합니다.

   ```text
   https://10000je.github.io/mihon-bookorbit-extension/repo.json
   ```

2. **탐색 → 확장**에서 `BookOrbit`을 설치하거나 업데이트하고, 신뢰 승인이 표시되면 승인합니다. [Releases](https://github.com/10000Je/mihon-bookorbit-extension/releases/latest)에서 APK를 직접 설치할 수도 있습니다.

## 사용법

1. BookOrbit의 **Settings → You → API keys**에서 원하는 라이브러리에 **Read** 권한을 가진 API 키를 발급합니다.
2. Mihon의 **탐색 → 소스 → BookOrbit I** 설정을 엽니다.
3. **HTTPS 서버 URL**과 **API 키**를 입력합니다. URL에 `/api/v1`은 붙이지 않습니다.
4. **연결 확인 / 라이브러리 재검색**을 실행합니다. 연결에 성공하면 접근 가능한 모든 라이브러리를 자동으로 적용합니다.
5. 소스 화면에 다시 진입합니다. **인기**는 모든 라이브러리의 만화를 표시하고, **필터 → 라이브러리 → 적용**으로 같은 서버·계정의 다른 라이브러리를 선택할 수 있습니다. 검색어와 라이브러리 필터도 함께 적용됩니다.
6. 다른 서버나 계정을 사용하려면 **BookOrbit II** 또는 **BookOrbit III**를 설정합니다.

탐색 화면에는 Mihon 기본 **인기 / 필터** 버튼이 표시되며 `최신`은 지원하지 않습니다. `인기`로 돌아가거나 필터의 **전체 라이브러리**를 선택하면 전체 목록을 표시합니다. 필터를 바꿔도 저장한 작품은 원래 라이브러리에서 읽습니다. 읽기 진행률은 Mihon에 저장됩니다.

기존 1~3번 소스의 ID와 작품 식별자는 이름 변경 후에도 유지됩니다. 업그레이드 후 **연결 확인 / 라이브러리 재검색**을 한 번 실행하고 소스 화면에 다시 진입하세요. 라이브러리를 추가·삭제하거나 권한을 바꾼 경우도 같습니다. 과거 4~6번 소스는 제거되었으며 기존 작품은 자동 이관되지 않습니다.

일반 검증 명령은 `./gradlew :app:testDebugUnitTest`이며 실서버 테스트는 기본 실행에서 제외됩니다. 에뮬레이터·기기·실서버 검증과 APK 빌드는 별도 요청이 있을 때만 수행합니다.
