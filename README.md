# BookOrbit Independent for Mihon

Mihon에서 개인 BookOrbit 서버의 만화를 읽기 위한 비공식 Android 확장입니다. 3개 소스를 제공하며, 각 소스에서 **필터 → 라이브러리**로 여러 라이브러리를 탐색합니다. CBZ·CBR·CB7 형식을 지원합니다.

Android 8.0 이상이 필요합니다. 기존 1.6.1은 Mihon 0.21.3과 BookOrbit 3.8.0에서 검증했습니다. 현재 1.6.2는 로컬 JVM 단위 테스트와 Debug/Release APK 빌드·서명 검사를 통과했습니다. 기기·실서버 재검증은 하지 않았으며, 아래 공개 배포 링크의 기존 APK에는 아직 반영되지 않았습니다. 로컬 설치용 파일은 `artifacts/bookorbit-independent-1.6.2-release.apk`입니다.

## 설치

1. Mihon의 **더보기 → 설정 → 탐색 → 확장 스토어**에 아래 주소를 추가합니다.

   ```text
   https://10000je.github.io/mihon-bookorbit-extension/repo.json
   ```

2. **탐색 → 확장**에서 `BookOrbit Independent`를 설치하고, 신뢰 승인이 표시되면 승인합니다. [Releases](https://github.com/10000Je/mihon-bookorbit-extension/releases/latest)에서 APK를 직접 설치할 수도 있습니다.

## 사용법

1. BookOrbit의 **Settings → You → API keys**에서 원하는 라이브러리에 **Read** 권한을 가진 API 키를 발급합니다.
2. Mihon의 **탐색 → 소스 → BookOrbit · 슬롯 1** 설정을 엽니다.
3. **HTTPS 서버 URL**과 **API 키**를 입력합니다. URL에 `/api/v1`은 붙이지 않습니다.
4. **연결 확인 / 라이브러리 재검색 → 기본 라이브러리 선택 / 적용**을 진행합니다.
5. 소스 화면에 다시 진입합니다. **인기**는 기본 라이브러리를 표시하고, **필터 → 라이브러리 → 적용**으로 같은 서버·계정의 다른 라이브러리를 선택할 수 있습니다. 검색어와 라이브러리 필터도 함께 적용됩니다.
6. 다른 서버나 계정을 사용하려면 슬롯 2~3을 설정합니다.

탐색 화면에는 Mihon 기본 **인기 / 필터** 버튼이 표시되며 `최신`은 지원하지 않습니다. `인기`로 돌아가면 기본 라이브러리를 표시합니다. 필터나 기본 라이브러리를 바꿔도 저장한 작품은 원래 라이브러리에서 읽습니다. 읽기 진행률은 Mihon에 저장됩니다.

기존 슬롯 1~3의 소스 ID와 작품 식별자는 유지됩니다. 업그레이드 후 라이브러리 재검색과 기본 라이브러리 적용을 한 번 실행하면 다른 라이브러리도 필터에 표시됩니다. 슬롯 4~6은 제거되며 그 슬롯의 기존 작품은 자동 이관되지 않습니다. 라이브러리를 추가·삭제하거나 권한을 바꾼 경우에도 재검색과 적용 후 소스 화면에 다시 진입하세요.

일반 검증 명령은 `./gradlew :app:testDebugUnitTest`이며 실서버 테스트는 기본 실행에서 제외됩니다. 에뮬레이터·기기·실서버 검증과 APK 빌드는 별도 요청이 있을 때만 수행합니다.
