# BookOrbit 서버 API 조사 체크리스트

**메모:** 아래 표는 조사할 API 역할을 정리한 것이며 **엔드포인트가 확정된 목록이 아닙니다**. Codex가 BookOrbit 공식 server 코드의 컨트롤러/DTO/서비스와 연결 서버 버전을 검사하여 채워야 합니다. 공개 API가 변할 수 있습니다.

| 영역 | 조사 대상 | 실제 경로/방식/DTO | 서버 버전/증거 | 완료 |
|---|---|---|---|---|
| 로그인/API key | 인증 및 권한 검사 | 미확정 | | ☐ |
| 라이브러리 목록 | id, name, 접근 권한 | 미확정 | | ☐ |
| 시리즈/도서 목록 | libraryId, 정렬, 페이지 크기 | 미확정 | | ☐ |
| 검색 | 쿼리, 라이브러리 범위, 페이징 | 미확정 | | ☐ |
| 책/파일 형식 | series→book→file, CBZ/CBR/CB7/EPUB | 미확정 | | ☐ |
| 표지 | URL, 인증, 캐시 | 미확정 | | ☐ |
| 챕터 목록 | 파일 id, 이름, 권순서 | 미확정 | | ☐ |
| 이미지 페이지 | 페이지 리스트와 이미지 바이트 | 미확정 | | ☐ |
| 오류 | 401/403/404/429/5xx 및 재시도 헤더 | 미확정 | | ☐ |

**후보로 알려진 과거 만화 API (검증 전 사용 금지)**: `/api/v1/cbz/files/{fileId}/pages` 및 `/pages/{index}` 형태가 BookOrbit 이슈 #481(2026-06-30)에 언급됨. **현재 공식 서버 코드에 아직 있는지 확인하고 구현**하세요. https://github.com/bookorbit/bookorbit/issues/481

조사 시 `server/src/modules` 및 `packages/`의 타입을 중심으로 컨트롤러 라우트, DTO의 실제 필드, API-key 지원 범위를 확인하세요. 코드를 그대로 복사하지 말고 새 클라이언트 구현에 필요한 계약만 기록하세요.
