## 저작권 정책

BookOrbit 코드는 AGPL-3.0-only 및 프로젝트의 별도 추가 조건이 적용될 수 있습니다. 서버 코드를 그대로 가져오거나 수정하여 배포하기 전, 라이선스/귀속 및 배포 의무를 먼저 검토하세요. 이 스타터는 기존 BookOrbit 구현을 복사하지 않고 API 역할만 기술합니다.

Mihon/tachiyomix 역시 해당 저장소의 공식 라이선스를 확인하고 사용하세요. 타 확장(Keiyoushi 포함)의 구현 소스는 이 프로젝트에 복사하지 않습니다.
